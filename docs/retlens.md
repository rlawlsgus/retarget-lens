# RetLens 사용 안내

RetLens(Retarget Lens)는 사람 모캡을 휴머노이드 로봇(지금은 Unitree G1, 29 DoF)에 옮겨 보고, 여러 소스를 비교하고, Isaac Sim 물리로 검증하는 데스크톱 프로그램입니다.

## 실행

- **설치판:** 릴리즈 zip을 풀고 `RetLens.exe`를 실행합니다(만드는 법은 [release.md](release.md)). 같은 폴더의 `retlens-cli.exe`는 AI·스크립트용 명령줄입니다(아래 "AI 연동").
- **저장소(개발 환경, [setup.md](setup.md)):**

```powershell
scripts\editor.bat                                   # 더블클릭으로도 실행
python tools\editor.py data\raw\cmu_bvh\02_01.bvh data\raw\amass_cmu_smplx\CMU\143\143_11_stageii.npz
```

블렌더·유니티처럼 패널을 도킹해 쓰는 Qt 프로그램입니다. 브라우저 비교 뷰어([pipeline.md](pipeline.md)의 "비교 뷰어")와 같은 기능을 편집기 화면으로 묶었고, 둘은 같은 코어(`khumanoid/app/scene.py`)를 씁니다.

```
+-- 메뉴 (파일·편집·보기·재생·물리·도움말) / 툴바 --------------------------+
|                                        | 계층: 불러온 모션, 보이기 체크   |
|   씬 뷰 (3D)                           +---------------------------------+
|                                        | 인스펙터 | 씬 설정 (탭)          |
+----------------------------------------+  선택한 모션의 속성·물리·동영상·지표 |
| 타임라인: 재생 버튼, 모션마다 트랙(오프셋·길이, 넘어진 시점 빨간 표시)      |
| 프로젝트 (폴더 탐색기) | 분석 (그래프·지표 표) | 비교 (겹쳐 비교) | 콘솔 (로그) |
+-- 상태바: Isaac 작업, 물리 모드, 현재 시각 ------------------------------+
```

## 화면과 기본 조작

- **패널:** 모든 패널은 끌어서 옮기거나, 탭으로 합치거나, 떼어 띄우거나, 닫을 수 있습니다. 배치는 다음 실행 때 그대로 열리고, "보기 > 레이아웃 초기화"로 위 배치로 돌아옵니다.
- **모션 추가:** 프로젝트 패널에서 두 번 클릭하거나 "추가"를 누릅니다. "파일 > 열기"(Ctrl+O)는 PC의 아무 폴더에서 엽니다. 탐색기에서 편집기 창으로 파일을 끌어다 놓아도 됩니다.
  - 프로젝트 패널은 `data/raw`, `data/retargeted`, `reports`(물리 결과) 같은 데이터 폴더를 트리로 보여 줍니다. 파일 옆에 CMU 동작 설명(예: 143_11 → Walk And Pick up Box)이 나오고, 검색 칸은 번호와 설명(예: `dance`)을 모두 찾습니다.
  - 처음 여는 사람 모션은 리타게팅에 수십 초가 걸립니다. 그동안에도 화면은 멈추지 않습니다.
- **선택:** 계층 패널이나 타임라인의 이름을 누르면 인스펙터에 그 모션의 정보가 나옵니다(종류, 파일, 길이, QC, IK 잔차, 표시·시간 오프셋, 물리 상태, 동영상, 지표 표). 계층 패널에서 우클릭하면 동영상 저장, 파일 위치 열기, 제거 메뉴가 나옵니다.
  - 계층 패널 이름 옆 체크와 인스펙터의 "보이기"는 같은 설정이라 한쪽을 바꾸면 다른 쪽도 바뀝니다.
- **분석 패널:**
  - 그래프는 "타임라인 따라가기"(기본 켬)가 눌려 있으면 재생 위치를 가운데에 두고 "구간" 길이만큼 보여 주며, 재생·스크럽을 따라 움직입니다. "구간"을 0으로 하면 전체 길이를 봅니다.
  - 그래프 배경을 끌면 좌우로 옮겨지고, 휠로 확대·축소합니다. 그러면 따라가기가 꺼지고, 버튼을 다시 누르거나 그래프를 두 번 클릭하면 다시 따라갑니다.
  - 지표 표의 칸은 좁게 유지합니다. "물리 판정"처럼 긴 값은 첫 항목만 줄여 보여 주고(예: "넘어짐 1회 외 2"), 칸에 마우스를 올리면 전체 문장이 나옵니다. 인스펙터 지표 표도 같습니다.
  - 지표 설명은 표 밑에 늘어놓지 않고 마우스를 올릴 때 나옵니다. 위쪽 막대의 "지표 설명"(?)에 올리거나 누르면 모든 지표가 주제별 표로 나오고, 표의 행 이름(인스펙터 지표 표도)에 올리면 그 지표 설명만 나옵니다. 설명 문구는 `khumanoid/app/scene.py`의 `METRIC_HELP`에 있습니다.
- **동영상:** 인스펙터의 "동영상 저장"은 비교 뷰어와 같은 Isaac 녹화입니다. 다 되면 "열기"로 기본 동영상 플레이어에서, "폴더"로 탐색기에서 엽니다.

## 열 수 있는 파일

사람 모션(BVH, FBX, AMASS SMPL-X npz)은 리타게팅해서 불러옵니다(기본 `--smooth 6`, 결과는 `data/cache/retarget/`에 캐시). 로봇 모션(npz, Unitree csv, GMR pkl)은 그대로 불러옵니다. Isaac 물리 결과(`*_sim.npz`)는 옆의 json에서 물리 지표를 읽어 함께 보여 줍니다.

- 물리 결과 파일은 로봇 관절각만 있어서 사람 스켈레톤이 없고, 이미 물리 결과라 물리 모드를 켜고 꺼도 그대로입니다. 사람과 물리 결과를 나란히 보려면 원본 사람 모션을 추가하고 물리 모드를 켭니다.

### C3D 마커

C3D 파일(`.c3d`, 예: `data/raw/cmu_c3d/02_01.c3d`)에는 마커 점만 있어 GMR로 바로 리타게팅할 수 없습니다.

- 그래서 같은 촬영의 솔버 결과를 찾아(같은 이름의 BVH → FBX → AMASS `<이름>_stageii.npz` 순, `data/raw` 등 라이브러리 폴더와 C3D와 같은 폴더) 그것을 리타게팅한 로봇을 쓰고, 사람 자리에 C3D 마커를 그립니다. 마커는 점, CMU 41마커 세트는 마커 사이 선으로도 그립니다. 없으면 무엇을 두면 되는지 알려 주는 메시지가 나옵니다.
- 마커는 솔버 스켈레톤 좌표로 옮겨 그립니다. 허리 마커 4개의 좌우 축을 스켈레톤 엉덩이 좌우 축에, 허리 마커 중심을 골반에 맞춥니다. CMU 샘플 9개는 BVH가 -90°, AMASS가 0–2° 돌아 있었고, 맞춘 뒤 골반 잔차는 0.2–3.5 cm입니다.
- 인스펙터에 마커 QC가 나옵니다: 마커 수, 빠진 비율(많이 빠진 마커 3개), 가장 긴 공백, 튐(두 샘플 사이 10 m/s 넘게 움직인 프레임, 라벨 뒤바뀜이나 유령 점). Vicon 모델 계산값(LFEM1–4 같은 분절 축 점)은 마커로 세지 않습니다.
- 동영상 저장은 Isaac이 사람을 파일 좌표 그대로 그리므로, 마커 대신 같은 촬영의 솔버 스켈레톤을 그립니다.

## 물리 모드

툴바나 물리 메뉴(P)에서 켭니다. 골반 보조 힘은 "물리 > 골반 보조 힘"에서 바꿉니다. 물리 계산이나 동영상 녹화를 처음 할 때 NVIDIA Omniverse 라이선스 동의 창이 한 번 뜹니다. 동의하면 다시 묻지 않습니다(`--isaac-accept-eula`로 미리 동의할 수도 있습니다).

- 켜면 각 로봇을 관절각대로 그리지 않고, Isaac Sim PhysX가 시뮬레이션한 결과로 바꿔 그립니다(중력, 마찰 바닥, 관절 토크 한계, 골반 보조 힘). 끄면 원래 기구학 재생으로 돌아옵니다.
- 결과가 없는 클립은 Isaac을 창 없이 백그라운드로 돌려 만듭니다. 한 번에 한 클립씩 돌고, 짧은 클립은 1분 남짓(대부분 Isaac 시작 시간), 11초 클립은 약 1분 30초입니다. 진행률은 패널과 각 로봇 이름표에 나옵니다.
- 결과는 모션 내용, `configs/physics.yaml`, 보조 힘 설정으로 키를 만들어 `data/cache/physics/`에 저장합니다. 다음에 켜거나 같은 동작을 다시 열면 바로 나옵니다.
- "골반 보조 힘"을 끄면(`--assist 0`) 따로 계산합니다. "Isaac 작업 취소"는 대기 중이거나 도는 중인 Isaac 프로세스(물리 계산·동영상 녹화)를 멈춥니다.
- 물리 모드에서는 분석 탭의 그래프·표도 시뮬레이션된 동작으로 잽니다("재생 방식" 행). 넘어진 클립은 이름표에 넘어진 시각과 1차 원인이 원인 시작부터 넘어진 뒤 0.5초까지 나옵니다(예: "넘어짐 2.07s · 발끝 걸림 1.47s부터").
- Isaac Sim의 EULA(NVIDIA Omniverse License Agreement)에 동의해야 돌아갑니다. RetLens는 물리 계산·동영상 녹화를 처음 할 때 동의 창을 띄우고 답을 기억합니다(`--isaac-accept-eula`는 미리 동의). 동의 창이 없는 브라우저 비교 뷰어는 `--isaac-accept-eula` 없이는 "EULA에 동의하지 않은 상태" 메시지로 실패하고, `retlens-cli`는 RetLens에서 한 번 동의했거나 사용자가 `--isaac-accept-eula`를 줄 때만 물리·녹화를 합니다.
- Isaac 위치는 RetLens "환경 설정"(설치 폴더나 `python.bat`), 환경변수 `KHUMANOID_ISAAC_PYTHON`, 지금 파이썬(k-humanoid 환경), `C:\isaacsim` 순서로 찾습니다(`khumanoid/settings.py`).
- 로봇은 NVIDIA 에셋 서버의 G1 USD를 받아 씁니다(인터넷 필요). 오프라인이나 사내 에셋을 쓰려면 환경 설정 "로봇 USD (선택)"에 USD 파일이나 Nucleus 주소를 넣습니다. 그러면 `--robot-usd`로 넘기고, 결과도 따로 캐시합니다.

## 분석 지표

- **분석:** 관절각·골반 높이·골반 속도 그래프(현재 시점 앞뒤 구간), 모션별 지표 표(관절 가속도·저크·최대 속도, 발바닥 미끄러짐, 바닥 관통, 발 최저점, 스윙 발 바닥 근접, 기준 대비 다리·전체 RMSE, QC, 물리 결과면 보조 힘·넘어짐·토크 한계 초과·판정), 기준 대비 관절별 RMSE 막대그래프를 보여 줍니다.
- **균형 표시**(기본 켬)는 바닥에 지지다각형(초록 선), CoM 투영(파랑), ZMP(빨강)를 그립니다. 분석 표에는 "CoM 지지 밖 %", "ZMP 지지 밖 %", "정적 불균형 %"가 나오고, 정적 불균형이 5%를 넘으면 QC가 WARN입니다(GMR MJCF 질량 기준, Isaac 에셋 기준 값과 0.1%p 이내).
- **스윙 발 바닥 근접**은 기구학 지표지만 물리 결과를 잘 예측합니다. 가장 느린 발바닥 점까지 0.5 m/s 넘게 움직이는 발이 그때의 바닥(디딤발 높이를 따라간 값, `analysis.floor_track`) 1 cm 안을 지나는 비율로, 높으면 물리에서 발끝이 걸려 비틀거립니다([results.md](results.md)의 "물리 재생 결과"). `--swing-clearance 2`(뷰어·비교 리포트에도 같은 옵션)로 보정한 결과를 볼 수 있습니다.
- 각 지표의 정의는 분석 탭 위쪽의 "지표 설명"(?)에 있습니다. QC 판정은 hard 플래그(결측, 튐, 관통, 떠 있음, 관절한계·속도, 넘어짐)가 붙은 프레임이 2% 이하면 PASS, 10% 이하면 WARN, 그 이상이면 FAIL입니다(자세한 기준은 [pipeline.md](pipeline.md)의 "검증(QC) 기준").

## 겹쳐 비교

툴바 "겹쳐 비교"(O)나 비교 탭에서 켭니다. 두 모션의 자세 차이를 한 자리에서 봅니다.

- 대상(B)의 골반을 기준(A)의 골반 위치로 옮기고, "골반 위치 + 방향"이면 골반이 향한 방향도 A에 맞춥니다. 걸어간 경로·방향 차이는 빠지고 자세 차이만 남습니다.
- A는 회색 반투명으로 그립니다. B는 A에서 허용 오차(기본 3 cm)보다 많이 벗어난 부위만 그리고, 노랑(허용 오차) → 주황(2배) → 빨강(3배 이상)으로 칠합니다. 회색만 보이면 둘이 겹친 것이고, 칠해진 B 부위 옆의 회색이 A가 있던 자리입니다. 비교하는 동안 두 모션의 사람 스켈레톤과 균형 표시는 숨깁니다.
- 부위 차이는 로봇 부품(고정 관절로 붙은 링크 묶음, G1 30개)마다 중심과 바깥쪽 점 12개를 두 자세에서 비교한 평균 거리입니다(`RobotBatch.part_deviation`).
- 비교 탭에는 지금 프레임의 평균·가장 큰 차이, 둘이 함께 재생되는 구간의 시간에 따른 차이 그래프(전체 평균과 몸통·머리/팔/다리별), 부위별 평균·최대·최대 시각·허용 오차를 넘은 시간 비율 표가 나옵니다. 표의 행을 두 번 클릭하면 그 시각으로 갑니다.
- A·B는 비교 탭에서 고르거나 계층 패널 우클릭("겹쳐 비교: 기준(A)으로 / 대상(B)으로")으로 정합니다. 시간 오프셋과 물리 모드를 그대로 따르므로, 분석 탭의 "기준에 시간 자동 정렬"을 먼저 하면 좋습니다.
- 예: CMU 02_01 BVH(A)와 같은 촬영의 AMASS SMPL-X(B)는 평균 2.7 cm 차이이고, 팔이 5.6–6.7 cm로 가장 많이 다릅니다(다리 3.2–3.5 cm, 몸통 1.2 cm).

## 환경 설정

"파일 > 환경 설정"(Ctrl+,)에서 외부 프로그램과 폴더의 위치를 정하고, 각 기능에 필요한 것이 있는지 바로 점검합니다.

- 항목: Isaac Sim(물리 모드·동영상), Blender 4.5(FBX), SMPL-X 모델 폴더(AMASS SMPL-X), 로봇 USD(선택, 비우면 NVIDIA 에셋 서버의 G1), 동영상 저장 폴더, 모션 폴더(프로젝트 패널에 더할 폴더). 로봇 모델·리타게팅(GMR)은 상태만 보여 줍니다.
- 칸을 비워 두면 자동으로 찾고(환경변수, 기본 설치 위치), 찾은 곳이 칸에 흐리게 나옵니다. 입력하는 동안 ✓/⚠와 "쓸 수 없는 기능", 고치는 방법이 바뀌고, "받는 곳"은 내려받기 페이지를 엽니다.
- 값은 `settings.json`(저장소에서는 `data/`, 설치판은 `%LOCALAPPDATA%\RetLens\`)에 저장되고, 편집기·비교 뷰어·명령줄 도구가 함께 씁니다. 명령줄 옵션(`--smpl-model-dir`, `--video-dir`, `--library`)을 주면 그쪽이 먼저입니다.
- 상태바 오른쪽 "환경 ✓ / ⚠ N"을 누르면 열립니다. 처음 실행할 때 빠진 것이 있으면 저절로 열립니다. 물리 모드·동영상 저장·FBX/SMPL-X 열기에 필요한 것이 없으면, 무엇이 없는지 알려 주고 환경 설정을 열 수 있게 합니다.
- 로봇 모델이 없으면 시작하지 않고 이유를 창으로 보여 줍니다.
- 파일 위치(프로그램 리소스, 사용자 데이터, 로그)는 "도움말 > 정보"에, 사용자 데이터 폴더는 "파일 > 데이터 폴더 열기"에 있습니다. 설치판은 캐시·로그를 `%LOCALAPPDATA%\RetLens`, 동영상을 `문서\RetLens\videos`에 둡니다.

## AI 연동

Claude 같은 AI 에이전트나 스크립트가 RetLens를 다루는 방법은 두 가지이고, 사용법은 AI 가이드(스킬)에 정리되어 있습니다.

- **명령줄 `retlens-cli`** (`python tools\retlens_cli.py`, 설치판은 `retlens-cli.exe`): 창 없이 돌고, 결과를 JSON 한 덩어리로 냅니다.
  - 할 수 있는 일: `info`(환경 점검), `library`, `inspect`(QC·지표·C3D QC), `metrics`(분석 표), `compare A B`(겹쳐 비교 수치와 가장 다른 순간), `align`, `retarget`, `c3d-qc`, `physics`, `video`.
  - 창과 같은 MotionScene을 써서 숫자가 화면과 같습니다(`khumanoid/app/api_core.py`).
- **로컬 HTTP API** (`khumanoid/app/api_server.py`): 떠 있는 창을 `http://127.0.0.1:8765`에서 조작합니다. 모션 열기, 재생·탐색, 보이기·오프셋, 시간 정렬, 겹쳐 비교, 물리 모드, 동영상, 카메라, 스크린샷, 지표를 다룹니다.
  - 127.0.0.1에서만 받고, 실행할 때마다 바뀌는 토큰이 필요합니다(`Authorization: Bearer`). 웹 페이지의 요청(Origin 헤더)은 거부합니다.
  - 주소와 토큰은 사용자 데이터 폴더의 `api.json`(`retlens-cli api`)에 있습니다. 환경 설정 "AI 연동"에서 끄거나 포트를 바꾸고, 상태바에 "API :8765"가 나옵니다.
- **AI 가이드 (스킬)** `.claude/skills/retlens/SKILL.md`: 두 방법의 사용법, 지표 해석, 자주 하는 작업, 지킬 것(Isaac 라이선스는 사용자만 동의, 라이선스 제한 데이터)을 Claude Code 스킬 형식으로 정리했습니다.
  - 이 저장소에서 Claude Code를 쓰면 자동으로 보입니다. 다른 곳에서는 `retlens-cli install-skill`이나 환경 설정의 "Claude Code에 스킬 설치"로 `~/.claude/skills/retlens`에 복사합니다.
  - 설치판에는 `_internal\ai\retlens\SKILL.md`로 들어갑니다.

## 구조 메모 (개발자용)

### 씬 뷰

- 3D는 viser 장면을 127.0.0.1의 빈 포트에 띄우고, Qt WebEngine(Chromium)으로 창 안에 보여 줍니다. viser 자체 제어판은 숨기고, 조작은 모두 Qt 패널에서 합니다.
- conda 환경에서는 Chromium 렌더러 샌드박스를 끕니다. 샌드박스 안의 렌더러가 conda의 Qt DLL을 찾지 못해 바로 죽기 때문입니다(0xC0000135). 씬 뷰는 로컬 씬 서버만 보여 주고, 다른 주소로 가는 링크는 기본 브라우저로 넘깁니다.
- 실행파일로 묶으면 DLL이 같은 폴더에 들어가므로 샌드박스를 켠 채로 돕니다.
- "보기 > 브라우저에서 씬 열기"로 같은 장면을 웹 브라우저에서도 볼 수 있습니다.
- 3D는 화면 배율에 맞춘 해상도로 고정해 그립니다(viser `fixedDpr`, 배율 100%면 1). viser는 원래 초당 약 38프레임보다 적게 그리면 해상도를 75%까지 낮추는데, 편집기는 재생 중 장면을 초당 30번 바꾸므로 늘 이 조건에 걸려 실행할 때마다 씬 뷰가 흐려지기도 했습니다. 고정해도 재생 프레임 수는 같았습니다(초당 약 40). 창을 배율이 다른 모니터로 옮기면 그 배율로 다시 불러옵니다.
- 로봇 메시는 브라우저로 보내기 전에 4 mm 격자로 단순화합니다(삼각형 38.8만 → 10만, 로봇 3대 로딩이 약 25초에서 5초로 줄어듦). `--mesh-cell 0`이면 원본 그대로 보냅니다.

### 재생이 끊기지 않게 한 방법 (`khumanoid/app/robots.py`, `scene.py`)

- Qt 창은 내장 Chromium의 화면을 GUI 스레드에서 합성합니다. 그래서 파이썬이 한 프레임에 오래 붙잡고 있으면(GIL) 3D 화면도 같이 멈춥니다. viser의 `ViserUrdf`는 로봇마다 링크 프레임 약 40개를 하나씩 옮겨 로봇 1대에 프레임당 약 80개 메시지, 10 ms가 들었습니다(3대에 46 ms → 3D 30 fps 미만).
- 지금은 로봇의 단단한 부품(고정 관절로 붙은 링크를 합친 30개)마다 배치 메시 하나에 모든 로봇을 인스턴스로 넣고, 순운동학은 numpy로 모든 로봇을 한 번에 계산합니다. 사람 스켈레톤·지지다각형·CoM·ZMP도 모든 모션이 노드 4개를 함께 씁니다. 모션 수와 상관없이 프레임당 메시지가 약 35개입니다.
- 장면은 별도 스레드에서 30 Hz로 갱신하고, 시각·표시 설정이 그대로면(일시정지) 아무것도 보내지 않습니다. 모션을 추가·제거해도 메시를 다시 보내지 않고 인스턴스 수만 바꿉니다.
- 측정(모션 7개, RTX 3070): 장면 갱신 4–8 ms/프레임, 3D 화면 멈춤 60 fps, 재생 중 60 fps 이상(프레임 간격 중앙값 15 ms).
